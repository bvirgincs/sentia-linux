# Licensing notes for `sentia-apt-worker`

- Original Sentia-authored source files in this directory are Apache-2.0.
- `sentia-apt-worker` links against `libapt-pkg` (GPL-2.0-or-later).
- Because Apache-2.0 is GPLv3-compatible (not GPLv2-only compatible), the
  combined linked worker binary must be distributed under GPLv3-compatible
  terms with corresponding source obligations met.
- Do **not** label the linked worker binary as Apache-only.
